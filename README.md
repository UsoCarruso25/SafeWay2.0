# SafaWay

Aplicación de seguridad comunitaria para el reporte, gestión y seguimiento de incidentes.

## Descripción

SafaWay es una aplicación orientada a fortalecer la comunicación y la gestión de situaciones de seguridad dentro de la comunidad.

## Módulos principales

- Gestión de usuarios
- Reporte de incidentes
- Alertas comunitarias
- Notificaciones
- Gestión y seguimiento de reportes
- Historial
